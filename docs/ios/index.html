小柯機器人台灣麻將

iPad／iPhone 版

安裝到這台 iPad／iPhone 下載 .ipa 檔（給 Mac 的 Finder／Apple Configurator 用）
請用 iPad／iPhone 的 Safari 開啟這一頁才能直接安裝。

安裝步驟

  1. 用 Safari 開這一頁，按上面紅色的「安裝」，再按「安裝」確認。
  2. 回到主畫面，等「小柯麻將」圖示的進度跑完。
  3. 以後有新版本，在遊戲裡按「關於 → 檢查更新」就會回到這一頁更新，牌譜與設定都會保留。

可以安裝的裝置

App Store 上架前，這個 .ipa 只能裝在開發者登記過的 iPad／iPhone 上；其他裝置按安裝會顯示「無法安裝」。
